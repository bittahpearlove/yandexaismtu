# Комплект Robomarvel: демонстрация и ученическая среда

Внутри каталога две папки.

- `demo/` - полный симулятор робота. Из него создается контейнер `robomarvel-demo`, который показывает демонстрацию: робот ездит, строит карту, сам доезжает до цели. Этот набор предназначен преподавателю.
- `student/` - стартовый набор ученика: только `Dockerfile` и `colcon-defaults.yaml`, папка `packages` пустая. Из него создается контейнер `robomarvel-sim`, в котором ученики работают весь курс.

В каждой папке лежит свой файл `ИНСТРУКЦИЯ.md` с пошаговыми командами.

## Файл образа

Готовый образ в комплект не входит: он весит около 2 ГБ. Возьмите файл своей архитектуры и положите его рядом с этим README либо укажите полный путь при загрузке.

- `robomarvel-sim-amd64.tar` - для обычных компьютеров на процессорах Intel и AMD;
- `robomarvel-sim-arm64.tar.gz` - для Mac на процессорах Apple M1 и новее.

На машине преподавателя файл `robomarvel-sim-amd64.tar` лежит в папке `C:\Users\Пользователь\robomarvel\`.

После загрузки образ получит имя `robomarvel-sim:latest` и станет доступен обоим наборам. Имя образа в командах запуска одинаковое, отличаются только имя контейнера и папка.

## С чего начать

1. Установите Docker, если он еще не установлен (порядок описан в первом шаге каждой инструкции).
2. Загрузите образ: `docker load -i robomarvel-sim-amd64.tar`.
3. Для демонстрации откройте `demo\ИНСТРУКЦИЯ.md`.
4. Для ученической среды откройте `student\ИНСТРУКЦИЯ.md`.

## Важное ограничение

Контейнеры `robomarvel-demo` и `robomarvel-sim` используют одни и те же порты (8000, 8765, 8554, 8889, 8189), поэтому одновременно они работать не могут. Перед запуском ученического контейнера остановите демонстрационный: `docker stop robomarvel-demo`.
