# Демонстрация Robomarvel: развернуть и запустить

Этот файл описывает, как из папки `demo` поднять демонстрационный контейнер `robomarvel-demo` и показать полный цикл: робот едет, строит карту, затем по готовой карте сам доезжает до цели.

Команды выполняются в двух местах: на самом компьютере (терминал PowerShell на Windows, Terminal на macOS и Linux) и внутри контейнера. Ниже явно указано, где именно.

## Быстрый запуск скриптами

Шаги 1-6 можно выполнить готовыми скриптами. В папке `demo` для Windows PowerShell:

```powershell
.\run-container.ps1
```

Если Windows не дает запускать файлы `.ps1`, обойдите политику так:

```powershell
powershell -ExecutionPolicy Bypass -File .\run-container.ps1
```

Скрипт загрузит образ (если его еще нет), создаст и запустит контейнер `robomarvel-demo`, терминал останется внутри контейнера. Во втором терминале запустите симулятор:

```powershell
.\start-simulator.ps1
```

По умолчанию это построение карты. Для навигации по готовой карте:

```powershell
.\start-simulator.ps1 -Slam localization -Nav true -Detection true -Db /src/maps/classroom_good.db
```

Для Linux и macOS те же скрипты: `./run-container.sh` и `./start-simulator.sh [slam] [nav] [detection] [db]`.

Ниже те же действия описаны по шагам вручную.

## Шаг 1. Установить и проверить Docker

Установите Docker Desktop (Windows, macOS) или Docker Engine (Linux). Затем проверьте в терминале компьютера:

```powershell
docker --version
docker info
```

`docker --version` печатает версию клиента. `docker info` печатает сведения о системе и работает только тогда, когда сам Docker запущен. Если вместо этого приходит `Cannot connect to the Docker daemon`, откройте Docker Desktop и дождитесь зеленого статуса либо на Linux выполните `sudo systemctl start docker`.

## Шаг 2. Загрузить образ

Файл образа положите рядом с этим комплектом. Для обычных компьютеров на Intel и AMD это `robomarvel-sim-amd64.tar`, для Mac на процессорах Apple M1 и новее - `robomarvel-sim-arm64.tar.gz`.

В терминале компьютера перейдите в папку с файлом образа и выполните:

```powershell
docker load -i robomarvel-sim-amd64.tar
```

Команда понимает и обычный архив `.tar`, и сжатый `.tar.gz`, распаковывать заранее не нужно. Ожидаемый вывод: `Loaded image: robomarvel-sim:latest`. Проверка:

```powershell
docker image ls
docker image inspect robomarvel-sim:latest --format "{{.Architecture}}"
```

В списке должна быть строка `robomarvel-sim`, а вторая команда печатает ту же архитектуру, что и `docker version --format "{{.Server.Arch}}"` на этой машине.

## Шаг 3. Разложить папку демонстрации

Скопируйте папку `demo` на компьютер под именем `robomarvel-demo` в домашний каталог:

- Windows: `C:\Users\<имя пользователя>\robomarvel-demo`
- macOS: `/Users/<имя пользователя>/robomarvel-demo`
- Linux: `/home/<имя пользователя>/robomarvel-demo`

Именно эта папка подключается внутрь контейнера и в дальнейшем видна там как `/src`.

## Шаг 4. Запустить контейнер

Откройте терминал компьютера, перейдите в папку `robomarvel-demo` и выполните команду (одной строкой):

```powershell
docker run -it --name robomarvel-demo -v "$(pwd):/src" -p 127.0.0.1:8765:8765 -p 127.0.0.1:8000:8000 -p 127.0.0.1:8554:8554 -p 127.0.0.1:8889:8889 -p 127.0.0.1:8189:8189/udp robomarvel-sim
```

Приглашение сменится на `student@<номер>:/src$`. Дальше все команды выполняются внутри контейнера, если не написано иное.

Порты: `8000` - VS Code в браузере, `8765` - мост для визуализации, `8554`, `8889`, `8189` - mediamtx для вебкамеры.

## Шаг 5. Собрать проект

Внутри контейнера:

```bash
cd /src
colcon build
source /src/install/setup.bash
```

Сборка занимает несколько секунд. Команда `source` подключает собранные пакеты к текущему терминалу и нужна в каждом новом терминале. Без нее следующая команда сообщит, что пакета `robomarvel_sim` не существует.

## Шаг 6. Запустить симулятор в режиме построения карты

Терминал 1 (тот, где выполнялся `docker run`) останется занят, это нормально:

```bash
ros2 launch robomarvel_sim sim.launch.py slam:=mapping nav:=false detection:=false
```

## Шаг 7. Телеуправление

Откройте второй терминал компьютера и войдите в уже запущенный контейнер:

```powershell
docker exec -it robomarvel-demo bash
```

Внутри сначала подключите пакеты, затем запустите телеуправление:

```bash
source /src/install/setup.bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

Клавиши работают только пока окно этого терминала в фокусе: `i` - вперед, `,` - назад, `j` и `l` - поворот на месте, `k` - стоп. Если робот дергается между нажатиями, добавьте повтор и уменьшите скорость поворота (нажмите `c` 4-5 раз):

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args -p repeat_rate:=10.0
```

Объезжайте помещение по периметру и вернитесь в стартовую точку: так робот узнает уже увиденное место и исправит накопившуюся ошибку.

## Шаг 8. Подключить Lichtblick

Откройте в браузере Lichtblick и подключитесь по адресу `ws://localhost:8765`. В настройках 3D-панели:

- Display frame (кадр отображения) - поставьте `map`;
- включите топики `/scan` и `/map`, при желании `/mapPath`;
- в разделе Transforms выключите `sim_world` и `sim_base`, они в отдельном дереве и без этого панель ругается.

Веб-версия может не подключиться к `localhost`: свежие версии Chrome блокируют обращение страницы к локальному адресу. Проверенный вариант - Lichtblick в Яндекс Браузере.

## Шаг 9. Сохранить карту

Когда карта устроит, остановите симулятор: в терминале 1 нажмите Ctrl+C один раз и дождитесь завершения процессов. Карта сохраняется автоматически, отдельной команды сохранения нет. Сделайте копию, иначе при следующем запуске в режиме построения исходный файл будет стерт:

```bash
cp /src/maps/rtabmap.db /src/maps/classroom_good.db
ls -lh /src/maps/
```

Файл `classroom_good.db` должен весить хотя бы несколько сотен килобайт.

## Шаг 10. Запустить навигацию по готовой карте

В терминале 1:

```bash
ros2 launch robomarvel_sim sim.launch.py slam:=localization db:=/src/maps/classroom_good.db nav:=true detection:=true
```

После Ctrl+C связь с Lichtblick разорвалась, подключитесь заново по тому же адресу. Карта появится сразу целиком, это признак работы по готовой карте.

## Шаг 11. Отправить цель

Из Lichtblick: в инструменте публикации в 3D-панели укажите топик `/goal` и тип `geometry_msgs/PoseStamped`, затем щелкните точку на карте (сначала точка, потом направление).

Или из третьего терминала компьютера:

```powershell
docker exec -it robomarvel-demo bash
```

```bash
source /src/install/setup.bash
ros2 topic pub --once -w 1 /goal geometry_msgs/msg/PoseStamped "{header: {frame_id: 'map'}, pose: {position: {x: 1.0, y: -0.5, z: 0.0}, orientation: {w: 1.0}}}"
ros2 topic echo /goal/status
```

Ожидается `GOAL ACCEPTED`, затем через некоторое время `SUCCESS`. Команду `echo` запускайте сразу после отправки цели: сообщения в этот топик приходят только в момент смены состояния.

## Остановка и повторный запуск

Остановить контейнер снаружи: `docker stop robomarvel-demo`. Снова запустить уже созданный контейнер и вернуться в его терминал:

```powershell
docker start -ai robomarvel-demo
```

## Частые проблемы

- `Conflict. The container name "/robomarvel-demo" is already in use` - контейнер уже создан. Не создавайте второй, используйте `docker start -ai robomarvel-demo`.
- `Bind for 127.0.0.1:8000 failed: port is already allocated` - порты заняты другим контейнером. Проверьте `docker ps` и остановите лишний, например `docker stop robomarvel-sim`.
- `Package 'robomarvel_sim' not found` - не выполнен `source /src/install/setup.bash` в этом терминале либо не сделан `colcon build`.
- Lichtblick не подключается - используйте Яндекс Браузер, подключайтесь после старта симулятора и не включайте в 3D одновременно `/map` и карту стоимости.
- `exec format error` сразу после запуска - загружен образ другой архитектуры, возьмите файл под свою машину.
